На телефон

Откройте ссылку и добавьте приложение на главный экран — оно работает без интернета.

Android. Откройте ссылку в Chrome, затем меню ⋮ → «Установить приложение».

iPhone. Откройте ссылку в Safari, нажмите «Поделиться» → «На экран “Домой”».

На компьютер с Windows

Установщик кладёт иконку на рабочий стол и в меню «Пуск».

Скачать установщик (.exe) Переносимая версия — без установки

Обе версии в одном релизе: установщик setup и переносимая portable. Windows может показать предупреждение о неизвестном издателе — это ожидаемо для сборки без подписи.

Что с данными

Всё хранится на вашем устройстве в браузере. Ничего не отправляется на сервер, пока вы сами не включите кабинет. Экспорт в JSON делает резервную копию целиком.
